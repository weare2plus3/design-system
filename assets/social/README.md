# Social

Profile pictures for social accounts. Most platforms (Instagram, X, YouTube, TikTok, Threads) crop avatars to a circle, which would clip the corners of the plain mark, so these fill the whole square with the mark's ink and scale the 2, 3 and + to sit inside the circle.

- `avatar-1080.png` / `avatar.svg`: the default everywhere. Ink ground, paper digits, `signal` +. Upload the 1080×1080 PNG; it works for circle and square crops (LinkedIn, Facebook pages).
- `avatar-light-1080.png` / `avatar-light.svg`: paper ground, ink digits. Only for a platform whose dark interface makes the ink version disappear; use one version across every account.

Account names: display name **TWO+THREE**; handle **@2plus3studio** everywhere (matches 2plus3.studio and fits every platform's handle rules). Bio starts with the tagline: "software. culture. gifts. books. design."
