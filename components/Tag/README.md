# Tag

A small pill label (one to three words, uppercase) for categories and status on cards and listings.

- **Provide:** `children` and optional `tone`.
- **neutral** (ink outline) is the default, for categories: "Picture book", "App".
- **signal** (sage fill) is for the single newest or featured thing on a page: "New".
- **ochre** (ochre fill) is for gifts and seasonal items: "Gift".
- Tags and radios are the only round things in the system. Don't make tags clickable; use a Button or link for actions.
