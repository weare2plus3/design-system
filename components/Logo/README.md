# Logo

The TWO+THREE logo drawn live from tokens, so it switches between light and dark with the theme: `ink` square and letters, `paper` digits, `signal` +s.

- **Provide:** optional `variant` (`lockup`, the default, or `mark`), `height` in px (48 by default), `mono` for the one-colour version, and `label` (pass `''` when a surrounding link already says "TWO+THREE home").
- Minimum height: 32px for the lockup, 20px for the mark. Keep clear space of a quarter of the mark's height all round.
- The wordmark is Teko outlined into shapes. Never retype it in the live font: the outlines are the logo.
- For files to download or place in print, use the `Logos` asset group; the shapes are identical.
- Placement: in the header on the studio's own sites. On a separate product's or project's site, in the footer only, as the maker's mark; the product's own icon and name take the header.
- Don't: recolour the parts, or place it on `signal` or `ochre`.
